# 🎮 I Putu Andika Prasetya — Terraria Pixel World Developer Portfolio

An interactive, subterranean excavation developer portfolio inspired by **Terraria**, crafted with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**.

![Terraria Developer Portfolio](public/video/terraria_day.mp4)

---

## 🌟 Highlights & Key Features

- **🏔️ Authentic Looping Terraria Video Background**:
  - Live MP4 video dynamic day & night surface biome backdrop.
- **🌓 Global Day / Night Cycle**:
  - Fully synchronised theme changing across all subterranean layers, typography, HUDs, and ambient color palettes.
- **🎵 Authentic Terraria OST Jukebox**:
  - Background audio playback for Day and Night themes with Web Audio API synthesized chiptune SFX for pickaxe clicks, pickups, and terminal commands.
- **⛏️ 6 Subterranean Depth Strata**:
  - **Stratum 00 (Surface, +120m)**: Overworld horizon with quick dispatch actions and altitude readout.
  - **Stratum 01 (Topsoil, 000m to -80m)**: Subsurface lithostratigraphy core extraction and telemetry meters.
  - **Stratum 02 (Subterranean Research Labs, -80m to -320m)**: Real excavated GitHub projects with interactive blueprint modals and live repository metrics.
  - **Stratum 03 (Lithosphere Conduits, -380m)**: Technical taxonomy, distributed databases, streaming protocols, and AI pipelines.
  - **Stratum 04 (Subterranean Biome Career Logs, -720m)**: Verified career milestones, including AI Automation Specialist (PT In Fashion), Data Analyst (PT Indo Apps Solusindo), and Android Developer (Bangkit Academy 2024).
  - **Stratum 05 (Obsidian Core, -1250m)**: Interactive retro CLI terminal (`andika_core_shell_v2`) with command parser and direct email dispatch conduits.
- **🛡️ Retro CRT Error Boundary**:
  - Protected root rendering with automatic subterranean breach detection.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6 + TypeScript
- **Styling**: Tailwind CSS with custom Terraria pixel color tokens and retro typography (`Press Start 2P`, `Silkscreen`, `JetBrains Mono`)
- **Audio Engine**: HTML5 Audio + Web Audio API Oscillator synthesizer
- **Icons**: Lucide React + Material Symbols Outlined
- **VFX**: Canvas Confetti for terminal celebrations and interactive achievements

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/andikaprasetyaaa/andika-prasetya-portofolio.git

# Enter project directory
cd andika-prasetya-portofolio

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
